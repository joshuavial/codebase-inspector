# codebase-inspector — interview
Purpose: plan agent skills that map a codebase into a structured model, plus a visualiser for multi-layer drill-down, cross-layer search and test overlay. Targets, read-only: sample-desktop first, then sample-apps, sample-saas, sample-monorepo and sample-dotnet.
Constraints read from repos (one-time): sample-desktop is TypeScript, Electron and a Node service (~100 code files, node --test). sample-saas is mostly data (txt/json), ~1.2k Python and ~700 TypeScript, docker-compose, one docs submodule. sample-monorepo is mostly markdown; its code sits in a submodule (Python, shell, TypeScript). A second checkout of that monorepo checked id stability. sample-dotnet is ASP.NET Core and Vue.
Status legend: ✅ decided · ❓ open · ⏸ deferred · ✂ rejected
